# Clean Archetecture Starter Template

The Clean Architecture Starter Template is a pre-configured Flutter project designed to follow best practices for scalability, maintainability, and separation of concerns. It provides a structured foundation for building robust Flutter applications by organizing code into distinct layers.

## Tech Stack

- ✅ State Management – Provider
- ✅ Networking and API Handling – Dio
- ✅ Dependency Injection - Getit
